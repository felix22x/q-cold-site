# Q-Cold — спокойный фокус с L-теанином

Лендинг бренда **Q-Cold**: cold brew, жвачка и шоколад с L-теанином и витаминами.

**Сайт:** https://felix22x.github.io/q-cold-site/

## Что на сайте

- Главный экран с крупной типографикой бренда
- Ролик с наливанием cold brew из банки Q-Cold
- Интерактивная 3D-сцена с шоколадом (Three.js): продукт реагирует на движение мыши
- Линейка продуктов: cold brew, жвачка, шоколад
- Блок с подпиской со скидкой

## Технологии

- HTML, CSS и JavaScript в одном файле, без сборки
- [Three.js](https://threejs.org/) для 3D-сцены
- Google Fonts
- Хостинг: GitHub Pages

## Структура

```
index.html      — вся страница: разметка, стили, скрипты
img/            — изображения продуктов (банка, шоколад, жвачка)
video/          — ролик cold brew и его превью
```

## Как запустить локально

Открыть `index.html` в браузере или запустить локальный сервер в папке проекта:

```
python -m http.server 8000
```

и перейти на http://localhost:8000
